## Sistema de Biblioteca Digital

Como preparación para el examen, desarrollé mi propio ejercicio práctico: un **Sistema de Biblioteca Digital**, con el objetivo de repasar y aplicar los conceptos vistos en clase hasta `HashSet`.

### Conceptos aplicados

- Herencia
- Polimorfismo
- Abstracción
- Encapsulamiento
- Interfaces
- Excepciones personalizadas
- CRUD
- Sobreescritura de métodos
- Validaciones
- Colecciones (`ArrayList` y `HashSet`)

Este proyecto fue realizado de forma independiente como práctica y repaso de los temas fundamentales de Programación Orientada a Objetos en Java.
